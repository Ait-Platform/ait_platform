Objective

Learn how mathematics helps solve everyday problems involving counting, addition, subtraction, multiplication, division, money and quantities.

Teacher Preparation

Gather everyday objects.
Examples: Coins, Bottle tops, Beans, Blocks, Pencils, Books, Toys.

Activity 1 – Counting Objects

Instruction

Place a collection of objects on a table. Examples:

  • • 10 beans
  • • 15 bottle tops
  • • 20 blocks

Teacher asks:

  • • How many objects are there?
{% if is_teacher_scoring %}

Expected Answer

Learner correctly counts the objects without skipping or repeating.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 2 – Grouping Objects

Instruction

Provide a collection of objects.

Teacher asks learner to:

  • • Group them into sets of 2.
  • • Group them into sets of 5.
  • • Group them into sets of 10.
{% if is_teacher_scoring %}

Expected Answer

Objects are arranged into equal groups.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 3 – Addition in Action

Instruction

Place 5 objects on the table. Add 3 more objects.

Teacher asks:

  • • How many objects are there now?

Repeat with different quantities.

{% if is_teacher_scoring %}

Expected Answer

Learner calculates the total number of objects.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 4 – Subtraction in Action

Instruction

Place 10 objects on the table. Remove 4 objects.

Teacher asks:

  • • How many objects remain?
{% if is_teacher_scoring %}

Expected Answer

Learner calculates the correct remainder.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 5 – Multiplication Through Groups

Instruction

Create equal groups.

Example:

  • • 3 groups with 4 blocks in each group.

Teacher asks:

  • • How many blocks are there altogether?
{% if is_teacher_scoring %}

Expected Answer

Learner calculates the total quantity.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 6 – Sharing Equally

Instruction

Place 12 objects on the table.

Teacher asks learner to share them equally between:

  • • 2 people
  • • 3 people
  • • 4 people
{% if is_teacher_scoring %}

Expected Answer

Each group receives an equal number of objects.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 7 – Money Mathematics

Instruction

Provide coins or pretend money. Examples:

  • • R2 coin
  • • R5 coin
  • • R10 note

Teacher asks:

  • • How much money do you have?
  • • If you spend R5, how much remains?
  • • What can you buy with the money available?
{% if is_teacher_scoring %}

Expected Answer

Learner correctly adds and subtracts money values.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 8 – Shopping Challenge

Instruction

Create a small pretend shop. Examples:

  • • Apple = R3
  • • Juice = R5
  • • Bread = R8

Teacher gives learner R20.

Teacher asks:

  • • What can you buy?
  • • How much change should you receive?
{% if is_teacher_scoring %}

Expected Answer

Learner calculates costs and change correctly.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 9 – Mathematics in Daily Life

Instruction

Teacher asks practical questions. Examples:

  • • There are 6 people and 12 apples. How many apples does each person get?
  • • A bus has 20 seats and 15 are occupied. How many seats are empty?
  • • You have R50 and spend R18. How much remains?
{% if is_teacher_scoring %}

Expected Answer

Learner uses appropriate calculations to solve the problem.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 10 – Mathematical Investigation

Instruction

Learner chooses a collection of objects.

Teacher asks learner to:

  • • Count them.
  • • Group them.
  • • Add more.
  • • Remove some.
  • • Share them equally.
{% if is_teacher_scoring %}

Expected Answer

Learner successfully performs all tasks using logical calculations.
