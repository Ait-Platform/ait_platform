Objective

Learn how objects are positioned relative to one another and how to describe location and direction.

Teacher Preparation

Collect any five everyday objects.
Examples: Book, Cup, Pencil, Ball, Toy.
Place them on a table.

Activity 1 – Position Words

Instruction

  1. Teacher places one object on the table.
  2. Teacher then places another object:
  1. Above it
  2. Below it
  3. Next to it
  4. In front of it
  5. Behind it

Teacher asks the learner to point to the object in the stated position.

{% if is_teacher_scoring %}

Expected Answer

The learner correctly points to the object in the requested position.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 2 – Follow Directions

Instruction

Place three objects in a line.

Teacher gives instructions:

  1. Move the ball to the left.
  2. Move the pencil to the right.
  3. Place the cup behind the book.
  4. Place the toy in front of the ball.
{% if is_teacher_scoring %}

Expected Answer

The learner places the objects in the correct positions.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 3 – Create a Position

Instruction

Teacher selects two objects.

Teacher asks:

  1. "Place the pencil behind the book."
  2. "Place the ball in front of the cup."
  3. "Place the toy next to the book."
{% if is_teacher_scoring %}

Expected Answer

Objects are placed correctly without assistance.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 4 – Describe What You See

Instruction

Teacher arranges five objects.

Learner describes:

  1. Which object is on the left?
  2. Which object is on the right?
  3. Which object is in the middle?
  4. Which object is behind another object?
  5. Which object is in front?
{% if is_teacher_scoring %}

Expected Answer

The learner uses position words accurately.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 5 – Human Directions

Instruction

Learner stands in an open area.

Teacher gives instructions:

  1. Take two steps forward.
  2. Take one step backward.
  3. Turn left.
  4. Turn right.
  5. Walk to the object.
{% if is_teacher_scoring %}

Expected Answer

Learner moves in the correct direction each time.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 6 – Navigation Challenge

Instruction

  1. Teacher places an object somewhere in the room.
  2. Learner must guide the teacher to the object using only directions.

Examples:

  1. Go forward.
  2. Turn left.
  3. Take two steps.
  4. Turn right.
{% if is_teacher_scoring %}

Expected Answer

The teacher can locate the object using the learner's instructions.

{% endif %}

{% endif %}

Final Checklist

As the observer, verify that the learner can successfully do all of the following:

✓ Identify positions
✓ Use direction words correctly
✓ Follow instructions involving movement
✓ Arrange objects according to directions
✓ Describe locations accurately
✓ Give directions to another person
