SECTION 1 – PRACTICAL LEARNING

CHAPTER {{ chapter.chapter_number }} – {{ chapter.title|upper }}

← Back

Objective

Learn how to identify, describe, predict and create patterns found in everyday life.

Teacher Preparation

Collect a variety of objects.
Examples: Bottle tops, Coins, Blocks, Pencils, Leaves, Buttons, Spoons, Cups.

Activity 1 – Spot the Pattern

Instruction

Teacher creates a simple pattern using objects.

Examples:

  • • Bottle Top, Coin, Bottle Top, Coin
  • or
  • • Red Block, Blue Block, Red Block, Blue Block

Teacher asks:

  • • What pattern do you see?
  • • What comes next?

Expected Answer

Learner correctly describes the repeating sequence and predicts the next item.

Activity 2 – Complete the Pattern

Instruction

Teacher creates an incomplete pattern.

Examples:

  • • Coin, Coin, Button, Coin, Coin, ___
  • or
  • • Cup, Spoon, Cup, Spoon, ___

Teacher asks:

  • • Which object should come next?

Expected Answer

Learner identifies the missing item based on the sequence.

Activity 3 – Create Your Own Pattern

Instruction

Provide several objects.

Learner creates a repeating pattern.

Examples:

  • • ABAB
  • • ABCABC
  • • AABBAABB

Expected Answer

The pattern repeats consistently according to a clear rule.

Activity 4 – Body Movement Patterns

Instruction

Teacher performs a sequence.

Examples:

  • • Clap, Tap, Clap, Tap
  • or
  • • Jump, Turn, Jump, Turn

Learner repeats the sequence.

Expected Answer

Learner performs the pattern accurately.

Activity 5 – Sound Patterns

Instruction

Teacher creates a sound pattern.

Examples:

  • • Clap, Clap, Snap
  • • Clap, Clap, Snap

Teacher asks:

  • • What comes next?

Expected Answer

Learner predicts the next sound correctly.

Activity 6 – Patterns in Nature

Instruction

Observe natural objects.

Examples:

  • • Leaves
  • • Flower petals
  • • Pinecones
  • • Tiles

Teacher asks:

  • • Do you see any repeating shapes?
  • • Do you see any repeating colours?

Expected Answer

Learner identifies repetition in shape, colour or arrangement.

Activity 7 – Growing Patterns

Instruction

Teacher creates a growing pattern.

Examples:

  • • 1 block
  • • 2 blocks
  • • 3 blocks
  • • 4 blocks

Teacher asks:

  • • What comes next?
  • • How do you know?

Expected Answer

Learner explains that the pattern increases according to a rule.

Activity 8 – Pattern Investigation

Instruction

Learner chooses objects and creates:

  • • A repeating pattern
  • • A growing pattern

Learner explains the rule.

Expected Answer

Learner describes how the pattern repeats or grows.

Chapter Competency Result

As the observer, verify that the learner can successfully do all of the following:

✓ Identify repeating patterns
✓ Complete patterns
✓ Predict what comes next
✓ Create patterns
✓ Recognise movement patterns
✓ Recognise sound patterns
✓ Identify patterns in nature
✓ Explain pattern rules
