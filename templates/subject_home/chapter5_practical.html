CHAPTER {{ chapter.chapter_number }} – {{ chapter.title|upper }}

Objective

Learn how to measure length, height, weight, distance and capacity using practical methods and everyday objects.

Teacher Preparation

Collect a variety of everyday items.
Examples: Ruler or tape measure, Pencil, Book, Bottle, Cup, Chair, School bag, Small stone.
If measuring tools are unavailable, learners may use hand spans, footsteps or other non-standard units.

Activity 1 – Measuring Length

Instruction

Select three objects (e.g. Pencil, Book, Spoon).

Measure each object using a ruler.

If no ruler is available, use finger widths or hand spans.

Teacher asks:

  • • Which object is longest?
  • • Which object is shortest?

Expected Answer

The learner obtains a measurement and correctly identifies longest and shortest objects.

Activity 2 – Measuring Height

Instruction

Select three objects of different heights (e.g. Bottle, Book, Chair).

Measure or compare their heights.

Teacher asks:

  • • Which object is tallest?
  • • Which object is shortest?

Expected Answer

The learner correctly ranks objects by height.

Activity 3 – Measuring Distance

Instruction

Choose two points (e.g. Door to desk, Chair to wall).

Measure the distance using:

  • • Footsteps
  • • Tape measure
  • • Metre stick

Teacher asks:

  • • How far apart are the two points?

Expected Answer

Learner records a reasonable measurement using available tools.

Activity 4 – Comparing Weight

Instruction

Provide several objects (e.g. Stone, Pencil, Book, School bag).

Learner lifts and compares them.

Teacher asks:

  • • Which object is heaviest?
  • • Which object is lightest?

Expected Answer

Learner identifies heavier and lighter objects correctly.

Activity 5 – Measuring Capacity

Instruction

Provide three containers (e.g. Cup, Bottle, Jug).

Fill each with water.

Teacher asks:

  • • Which holds the most?
  • • Which holds the least?

Expected Answer

Learner identifies the container with the greatest and smallest capacity.

Activity 6 – Non-Standard Measurement

Instruction

Measure a table using hand spans.

Measure a room using footsteps.

Teacher asks:

  • • How many hand spans long is the table?
  • • How many steps across is the room?

Expected Answer

Learner obtains consistent measurements using the chosen unit.

Activity 7 – Measurement Investigation

Instruction

Select an everyday object (e.g. School bag, Water bottle, Book).

Teacher asks:

  • • How long is it?
  • • How tall is it?
  • • Is it heavy or light?
  • • How much can it hold?

Expected Answer

Learner applies different measurement concepts to the same object.

Activity 8 – Practical Problem Solving

Instruction

Teacher presents a scenario. Examples:

  • • Will this book fit inside the drawer?
  • • Can this bottle fit on the shelf?
  • • Which container should be used to carry more water?
  • • Which bag is best for carrying heavy items?

Expected Answer

Learner makes decisions based on size, height, weight or capacity.

Chapter Competency Result

As the observer, verify that the learner can successfully do all of the following:

✓ Measure length
✓ Measure height
✓ Measure distance
✓ Compare weight
✓ Compare capacity
✓ Use standard measurement tools
✓ Use non-standard measurement methods
✓ Apply measurement to solve practical problems
