Objective

Learn what an object is and discover the properties of objects through observation.

Teacher / Parent Preparation

Ask the learner to collect any three objects from their environment.
Examples: Cup, Spoon, Book, Leaf, Shoe, Toy, Bottle, Fruit.
The learner may choose any objects available.

Activity 1 – Finding Objects

Instruction

  • Look around your environment.
  • Select three objects.
  • Place them on a table.

Expected Answer

The learner can correctly identify three separate objects.

Activity 2 – Discovering Properties

Instruction

  • Pick up Object 1.
  • Explore it using your senses.

Teacher asks:

  • • What colour is it?
  • • What shape is it?
  • • Is it hard or soft?
  • • Is it smooth or rough?
  • • Is it heavy or light?

Repeat for Object 2 and Object 3.

Expected Answer

The learner correctly describes observable properties.

Example (Apple): Red, Round, Smooth, Light, Firm.
{% if is_teacher_scoring %}
{% endif %}

Activity 3 – Comparing Objects

Instruction

Place Object 1 and Object 2 side by side.

Teacher asks:

  • • Which is bigger?
  • • Which is heavier?
  • • Which is smoother?
  • • Which is easier to hold?

Expected Answer

The learner identifies at least one similarity and one difference.

Example: Cup and bottle are both containers. Bottle is taller. Cup is wider.
{% if is_teacher_scoring %}
{% endif %}

Activity 4 – Hidden Properties

Instruction

  • Teacher selects one object.
  • Learner closes eyes.
  • Teacher places the object in the learner's hands.
  • Learner identifies the object by touch only.
  • Repeat with other objects.

Expected Answer

The learner identifies the object using texture, shape, size or weight.

{% if is_teacher_scoring %}
{% endif %}

Activity 5 – Observation Challenge

Instruction

  • Learner studies all three objects for 30 seconds.
  • Teacher covers the objects.
  • Teacher removes one object.
  • Cover is removed.
  • Learner identifies the missing object.

Expected Answer

The learner correctly identifies the missing object.

{% if is_teacher_scoring %}
{% endif %}

Activity 6 – Purpose Investigation

Instruction

Teacher asks:

  • • What is this object used for?
  • • Who might use it?
  • • What problem does it solve?
  • • What happens if we do not have it?

Expected Answer

The learner explains the function of the object.

Example (Spoon): Used for eating food. Used by people when eating meals. Helps move food from plate to mouth. Without it, eating some foods becomes more difficult.

Final Checklist

As the observer, verify that the learner can successfully do all of the following:

✓ Identify an object
✓ Identify properties of an object
✓ Compare objects
✓ Observe changes
✓ Recognise objects through touch
✓ Explain the purpose of an object
