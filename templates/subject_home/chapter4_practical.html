Objective

Learn how to make sensible guesses using observation before measuring, counting or calculating.

Teacher Preparation

Collect a variety of everyday items.
Examples: Marbles, Coins, Beans, Blocks, Bottles, Cups, Books, Pencils.

Activity 1 – How Many?

Instruction

Place a group of objects on a table (e.g. Beans, Coins, Blocks).

  1. Learner observes without counting.

Teacher asks:

  • • How many objects do you think there are?

After the estimate, the learner counts the objects.

{% if is_teacher_scoring %}

Expected Answer

The estimate should be reasonably close to the actual quantity.

{% endif %}

{% endif %}

Activity 2 – Which Holds More?

Instruction

Place three containers of different sizes on a table (e.g. Cup, Bottle, Jug).

Teacher asks:

  • • Which container will hold the most water?
  • • Which will hold the least?
{% if is_teacher_scoring %}

Expected Answer

The learner identifies the largest and smallest capacity containers.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 3 – Which Is Heavier?

Instruction

Place three objects on a table (e.g. Book, Stone, Pencil).

Learner may lift them.

Teacher asks:

  • • Which object do you think is heaviest?
  • • Which is lightest?
{% if is_teacher_scoring %}

Expected Answer

The learner identifies the approximate weight differences.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 4 – Distance Estimation

Instruction

Select two points (e.g. Door to desk, Chair to wall).

Teacher asks:

  • • How many steps away is it?

Learner estimates first.

Then learner walks and counts.

{% if is_teacher_scoring %}

Expected Answer

Estimate is reasonably close to the actual number of steps.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 5 – Time Estimation

Instruction

  1. Teacher asks learner to close their eyes.

Teacher says:

"Raise your hand when you think one minute has passed."

Teacher times the activity.

{% if is_teacher_scoring %}

Expected Answer

Estimate is reasonably close to one minute.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 6 – Fill the Container

Instruction

Show an empty container and provide small objects (e.g. Marbles, Blocks, Coins).

Teacher asks:

  • • How many objects will fit inside?

Learner estimates first.

Objects are then added and counted.

{% if is_teacher_scoring %}

Expected Answer

Estimate is based on observation and reasoning.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 7 – Estimation Challenge

Instruction

Teacher presents several situations.

Examples:

  • • How many books are on the shelf?
  • • How many learners are in the room?
  • • How many chairs are in the hall?
  • • How many leaves are on a branch?

Learner provides estimates without counting.

{% if is_teacher_scoring %}

Expected Answer

Estimates are realistic and not random.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 8 – Reflection Through Prediction

Instruction

Teacher asks:

  • • Why is estimation useful?
  • • When would you estimate instead of count?
  • • What helped you make a good estimate?
{% if is_teacher_scoring %}

Expected Answer

The learner explains that estimation is a sensible guess made before exact measurement or counting.

{% endif %}

{% endif %}
