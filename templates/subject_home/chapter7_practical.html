Objective

Learn how objects relate to one another in space and develop the ability to visualise, manipulate and navigate physical environments.

Teacher Preparation

Collect everyday objects. Provide an open space for movement activities.
Examples: Blocks, Books, Cups, Boxes, Toys, Chairs.

Activity 1 – Understanding Position

Instruction

Place three objects on a table.

Teacher asks:

  • • Which object is nearest to you?
  • • Which object is furthest away?
  • • Which object is between the other two?
{% if is_teacher_scoring %}

Expected Answer

Learner accurately identifies relative positions.

{% endif %}

Activity 2 – Building Structures

Instruction

Provide blocks, books or boxes.

Teacher asks learner to:

  • • Stack objects.
  • • Place one object beside another.
  • • Place one object on top of another.
  • • Place one object underneath another.
{% if is_teacher_scoring %}

Expected Answer

Objects are positioned as instructed.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 3 – Copy the Arrangement

Instruction

  1. Teacher creates an arrangement using objects.
  2. Learner observes for 30 seconds.
  3. Learner recreates the arrangement.
{% if is_teacher_scoring %}

Expected Answer

The learner recreates the structure with correct positioning.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 4 – Rotation Investigation

Instruction

Place an object on a table.

Teacher asks learner to:

  • • Turn it halfway.
  • • Turn it completely around.
  • • Turn it to face a different direction.
{% if is_teacher_scoring %}

Expected Answer

Learner successfully changes orientation as instructed.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 5 – Viewpoint Challenge

Instruction

Place an object in the centre.

Teacher asks learner to observe from:

  • • Front
  • • Back
  • • Left side
  • • Right side

Teacher asks:

  • • What changes?
  • • What stays the same?
{% if is_teacher_scoring %}

Expected Answer

Learner identifies features visible from different positions.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 6 – Navigation Course

Instruction

Create a simple obstacle course.

Examples:

  • • Walk around a chair.
  • • Move between two tables.
  • • Walk under a rope.
  • • Step over a box.
{% if is_teacher_scoring %}

Expected Answer

Learner successfully completes the course.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 7 – Mental Mapping

Instruction

Teacher asks learner to describe a familiar place (e.g. Bedroom, Classroom, Kitchen).

Teacher asks:

  • • What is next to the door?
  • • What is opposite the window?
  • • What is in the corner?
{% if is_teacher_scoring %}

Expected Answer

Learner recalls spatial relationships correctly.

{% endif %}
{% if is_teacher_scoring %}
{% endif %}

Activity 8 – Design Challenge

Instruction

Provide several objects.

Teacher asks learner to build:

  • • A bridge
  • • A tower
  • • A house
  • • A simple structure

Learner explains:

  • • Why objects were placed where they were.
  • • How the structure stays balanced.
{% if is_teacher_scoring %}

Expected Answer

Learner creates a stable structure and explains positioning decisions.

{% endif %}
