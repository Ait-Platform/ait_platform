Objective

Learn how to compare objects by identifying similarities, differences and measurable characteristics.

Teacher Preparation

Collect any four everyday objects of different sizes, weights or shapes.
Examples: Book, Pencil, Cup, Bottle, Spoon, Shoe, Toy.

Activity 1 – Bigger or Smaller

Instruction

Place two objects side by side.

Teacher asks:

  • • Which object is bigger?
  • • Which object is smaller?

Repeat with different pairs.

Expected Answer

The learner correctly identifies which object occupies more or less space.

Activity 2 – Longer or Shorter

Instruction

Place two objects next to each other.

Examples:

  • • Pencil and spoon
  • • Ruler and pen

Teacher asks:

  • • Which is longer?
  • • Which is shorter?

Expected Answer

The learner correctly compares object lengths.

{% endif %}

Activity 3 – Heavier or Lighter

Instruction

Learner holds one object in each hand.

Teacher asks:

  • • Which feels heavier?
  • • Which feels lighter?

Repeat using different objects.

Expected Answer

The learner identifies which object requires more effort to hold.

Activity 4 – Similarities

Instruction

Place two objects together.

Teacher asks:

• What is the same about these objects?

Examples:

  • • Both are round.
  • • Both are made of plastic.
  • • Both can hold things.

Expected Answer

The learner identifies a shared characteristic or purpose.

{% endif %}

Activity 5 – Differences

Instruction

Using the same objects, ask:

• What is different about these objects?

Examples:

  • • Different colour.
  • • Different size.
  • • Different shape.
  • • Different use.

Expected Answer

The learner identifies a meaningful difference between objects.

{% endif %}

Activity 6 – Sorting Challenge

Instruction

  • Provide several objects.
  • Ask learner to sort them into groups.

Examples (Group by):

  • • Size
  • • Shape
  • • Colour
  • • Weight
  • • Material

Expected Answer

Objects are grouped using a clear comparison rule.

{% if is_teacher_scoring %}
{% endif %}

Activity 7 – Ranking Objects

Instruction

Provide three or more objects.

Ask learner to arrange them:

  • • Smallest to largest
  • • Lightest to heaviest
  • • Shortest to longest

Expected Answer

Objects are ranked accurately according to the selected property.

{% if is_teacher_scoring %}
{% endif %}

Activity 8 – Comparison Investigation

Instruction

Teacher selects two objects.

Learner must explain:

  • • Which is larger?
  • • Which is heavier?
  • • Which is easier to carry?
  • • Which would cost more to replace?
  • • Which would be more useful at home?

Expected Answer

Learner provides logical reasons based on observable properties.
