Objective

Learn how to use facts, clues, evidence and reasoning to make correct decisions and reach sensible conclusions.

Teacher Preparation

Gather everyday objects and prepare simple scenarios.
Examples: Cup, Key, Book, Pencil, Ball.

Activity 1 – Finding the Correct Object

Instruction

Place three objects on a table. Teacher gives clues.

Example:

  • • I am used for writing.
  • • I am longer than a key.
  • • I am usually found in a pencil case.

Teacher asks:

  • • Which object am I describing?

Expected Answer

Learner correctly identifies the object that matches all clues.

Activity 2 – True or False

Instruction

Teacher makes statements about visible objects.

Examples:

  • • The book is larger than the pencil.
  • • The ball is square.
  • • The cup can hold water.

Teacher asks:

  • • Is the statement true or false?

Expected Answer

Learner correctly identifies true and false statements using observation.

Activity 3 – What Does Not Belong?

Instruction

Place four objects together.

Example:

  • • Apple
  • • Banana
  • • Orange
  • • Pencil

Teacher asks:

  • • Which object does not belong?
  • • Why?

Expected Answer

Learner identifies the item that differs from the others and explains why.

Activity 4 – Following Evidence

Instruction

Teacher creates a simple scenario.

Example:

  • • The floor is wet.
  • • There is an open tap.
  • • Water is near the sink.

Teacher asks:

  • • What probably happened?

Expected Answer

Learner concludes that water likely came from the tap.

Activity 5 – Elimination Challenge

Instruction

Place three objects on a table. Teacher gives clues.

Example:

  • • It is not the book.
  • • It is not the pencil.

Teacher asks:

  • • Which object must it be?

Expected Answer

Learner identifies the remaining possible object.

Activity 6 – Sequence Logic

Instruction

Teacher performs actions. Example:

  • • Clap
  • • Stamp
  • • Clap
  • • Stamp

Teacher stops.

Teacher asks:

  • • What should happen next?

Expected Answer

Learner predicts the next correct action.

Activity 7 – Cause and Effect

Instruction

Teacher asks practical questions. Examples:

  • • What happens if a plant is never watered?
  • • What happens if a ball is kicked?
  • • What happens if a light switch is turned off?

Expected Answer

Learner explains the likely outcome.

Activity 8 – Solving a Simple Mystery

Instruction

Teacher presents a situation.

Example: Three learners had a ball.

Teacher says:

  • • Sipho was reading a book.
  • • Amina was drawing.
  • • John was playing outside.

Teacher asks:

  • • Who most likely had the ball?

Expected Answer

Learner selects the person most likely connected to the evidence.

Activity 9 – Real-Life Problem Solving

Instruction

Teacher presents a practical problem. Example:

A learner wants to carry many books.

Teacher asks:

  • • Which would be better: a plastic bag or a school bag?
  • • Why?

Expected Answer

Learner selects the most suitable option and explains the reasoning.

Activity 10 – Logic Investigation

Instruction

Teacher places five objects on a table.

  • Learner must create three clues describing one object.
  • Another person must identify the object using the clues.

Expected Answer

Clues are accurate, useful and lead to the correct object.
