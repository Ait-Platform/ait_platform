Theory Review

Key Concepts

Object

An object is anything that can be seen, touched or observed.

Examples:

  • Book
  • Pencil
  • Chair
  • Ball

Property

A property is a characteristic that describes an object.

Examples:

  • Colour
  • Size
  • Shape
  • Weight
  • Texture
  • Purpose

Comparison

Comparison is the process of identifying similarities and differences between objects.

Object A: Apple

Properties:

  • Red
  • Round
  • Smooth
  • Edible

Object B: Orange

Properties:

  • Orange
  • Round
  • Textured
  • Edible

Similarities:

  • Both are fruit.
  • Both are round.
  • Both can be eaten.

Differences:

  • Different colours.
  • Different textures.
  • Different tastes.

Chapter Summary

  • •An object is anything that can be observed.
  • •A property is a characteristic of an object.
  • •Objects can be compared using: Colour, Shape, Size, Weight, Texture, Purpose.
  • •Comparison helps us make observations, solve problems and make decisions.
